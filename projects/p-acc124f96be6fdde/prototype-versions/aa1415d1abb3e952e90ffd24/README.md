# 学生社团桌面端原型

本目录是学生社团 2.0 的统一桌面端原型工程。当前已实现教师桌面端；学生桌面端将在每个业务部分完成“1.0 证据 → 用户想法 → 综合评估”后逐步加入。

## 当前范围

- 教师桌面端产品范围：学生社团主页、分析报告、社团审核、社团学分审核、配置，共五个一级页面。社团审核页面用 Tab 切换社团申报、结束申请、延续申请三个审核列表；原型生成器页面树中，每个列表分别关联对应审核工作台。
- 学生桌面端：尚未开始页面设计，不在缺少 1.0 证据时预设页面。
- 手机端：桌面端主流程确认后再展开，不能简单缩小桌面页面。

## 代码结构

```text
src/
  app/                         原型入口与端路由
  apps/
    teacher-desktop/           教师桌面端
      TeacherDesktopApp.jsx
      fixtures.js              教师端演示数据
      pages.jsx                一级页面、审核目录、审核列表与工作台
      shell.jsx                平台框架与导航
      ui.jsx                   当前页面共用控件
  App.jsx                      稳定入口
  main.jsx
  styles.css                   当前教师桌面端样式
docs/
  PRODUCT-PLAN.md              设计顺序、评估门槛与配置分析
```

当前只抽取已经实际复用的教师端结构。学生端出现后，再识别真正共用的业务模型、设计变量和组件，避免为了“共用”提前制造错误抽象。

## 工作约定

1. 每个业务部分开始前，由用户提供 1.0 实现和初步想法。
2. 先拆解事实、问题、建议和待确认项，再决定 2.0 页面与交互。
3. 评估结论确认后才修改原型。
4. 新调研与现有实现冲突时，先判断属于配置、字段、流程、权限还是数据模型变化，再决定局部修改或调整方案。

原型入口文件需要通过项目预览服务访问，不能作为独立 HTML 双击打开。
